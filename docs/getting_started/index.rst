Getting Started
===============

The fluorescence model page shows how
to construct and inspect models; the MCMC fitting page shows how to fit
them to data; the production rate page converts fitted column densities into
molecular production rates; and the utilities page covers helper functions that can be useful.

Throughout the documentatino all the examples are for CN, but the to C\ :sub:`2`, Fe or your own support list.
If you still want more examples check the WorkFlow.ipynb Jupyter notebook in the GitHub repository (`link <https://github.com/baltasarluco/CometSpec>`__).

**The currect CometSpec version just support fluorscence models that assumes fluorescence equilibrium**
